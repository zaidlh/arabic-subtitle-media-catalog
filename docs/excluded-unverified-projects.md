# Excluded or unverified search-result categories

The GitHub search returned repositories described as downloaders, streaming add-ons, or tools for obtaining anime and films with Arabic subtitles. Because repository descriptions alone do not establish authorization, licensing, or lawful distribution rights, these categories are excluded from the catalog as media sources.

This document does not reproduce operational links, copied files, credentials, or instructions for accessing unauthorized content. The purpose of documenting the exclusion is to make the catalog’s screening policy transparent: a search hit is not treated as a lawful source merely because it is public on GitHub.

Projects that provide generic subtitle APIs, translation utilities, encoding tools, media players, or metadata workflows may be listed as references when their purpose can be described without facilitating infringement. Users must independently check each project’s license and the rights of any media or subtitle files they access through it.
