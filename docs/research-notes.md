# Research notes

## Method

The search combined GitHub repository discovery with primary-source checks on legal or institutional media pages. GitHub results were screened for direct relevance to Arabic subtitles, subtitle metadata, playback, translation, or lawful public-domain cataloging. Media entries were not accepted solely because a search result claimed that subtitles existed; the source page had to expose Arabic subtitle evidence or an Arabic timed-text record.

## Verified media entries

*The Night of Counting the Years* is listed by the Internet Archive as a 1969 Egyptian film and its item metadata explicitly states that separate Arabic and English SRT files are included. The same item is labeled Public Domain by the Internet Archive.[1]

*Sintel* is an independently produced Blender Foundation short film. The Wikimedia Commons file page describes the source and reuse context and lists an Arabic timed-text file under the available subtitles.[2]

The Library of Congress National Film Registry page identifies a selection of public-domain films in an online collection, including *St. Louis Blues*, *Popeye the Sailor Meets Sindbad the Sailor*, *Within Our Gates*, and *The Great Train Robbery*.[3] Those entries are included as source candidates only because Arabic subtitles were not confirmed on the page checked.

## GitHub repository notes

The GitHub project list is a reference index, not a claim that every project is safe, current, or authorized for every use. License information reflects the search metadata available at collection time and should be rechecked before code is copied or bundled. The catalog intentionally excludes repositories whose apparent purpose is unauthorized access to copyrighted films, anime, or streaming platforms.
