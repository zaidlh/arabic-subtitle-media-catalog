# Arabic-Subtitle Media Catalog

This repository is a curated index of **movies, short films, series-related tools, and authorized media resources that provide or support Arabic subtitles**. It is intended to help viewers and developers discover lawful sources without hosting or redistributing copyrighted video files.

> **Scope:** This project stores metadata and links only. It does not include pirated films, unauthorized streaming links, copied copyrighted subtitle files, download instructions for infringing sources, or credentials for third-party services.

## Catalog contents

The current catalog contains two complementary sections. The first lists media items whose source pages explicitly expose Arabic subtitles and provide a rights or reuse context. The second lists GitHub repositories that support Arabic-subtitle playback, generation, translation, validation, encoding, or lawful cataloging. GitHub projects are linked for reference and remain owned by their respective authors.

| File | Purpose |
|---|---|
| `data/legal-arabic-subtitle-media.csv` | Verified media entries with source, subtitle evidence, and rights notes |
| `data/github-arabic-subtitle-projects.csv` | GitHub projects relevant to Arabic subtitles, filtered for lawful documentation use |
| `docs/research-notes.md` | Research method, inclusion rules, and source notes |
| `docs/excluded-unverified-projects.md` | High-level record of search-result categories excluded from the catalog |

## Inclusion rules

An entry is included as a verified media item only when a primary or institutional source indicates that Arabic subtitles or Arabic timed text are available and provides a usable rights, public-domain, or reuse context. Availability on a platform alone is not treated as proof that redistribution is permitted. When rights are unclear, the entry is marked for review and the repository links to the original page rather than copying the asset.

GitHub projects are included as references when their repository description or documentation is directly relevant to Arabic subtitles. Projects that appear to facilitate unauthorized access to copyrighted movies or series are not used as media sources. They may be recorded in the exclusion notes without reproducing their links, files, or operational instructions.

## Contributions

Please submit source links, rights information, and subtitle evidence with every proposed entry. Do not commit movie files, unauthorized subtitle files, scraped credentials, or links whose purpose is to bypass a platform’s access controls.
